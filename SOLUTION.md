# Решение

## Сколько заняло

Чуть больше 10 минут.

## Что сделано и что не успел

Сделано:
- экран матчей: загрузка, ошибка/повтор, пустой список, фильтр, обновление + `UpdatedAgo`;
- починены звёздочки и таймер «обновлено N сек назад», звезда на каждой карточке;
- бонус: поиск по названию клуба;
- этот `SOLUTION.md`.

Не брал: сохранение избранного, тесты, тёмная тема.

## Решения

Фильтр:
- «Предстоящие» — только `scheduled` (матч ещё не начался).
- «Завершённые» — только `finished`.
- `live` и `postponed` показываю только во «Все»: live уже идёт (не предстоящий и не завершённый), postponed — ни то ни другое, дату могут ещё не назначить.

Неочевидные случаи в данных:
- `score: null` у ещё не сыгранных — счёт просто не рисую.
- `startsAt: null` у отложенного — пишу «Дата не назначена».
- у live есть `minute` — добавляю к статусу («Идёт, 67'»).
- URL в `config.ts` был с плейсхолдером `OWNER/REPO` — подставил реальный raw URL репозитория, иначе загрузка не работала.

Бонус: поиск по клубу — фильтрую хозяев и гостей без учёта регистра, поверх статуса. Выбрал это, потому что без новых библиотек и сразу видно в UI. Если обновление падает, а старые матчи уже есть — показываю красную плашку с «Повторить», а не молчаливый сбой.

## Баги из части 2

1. Звёздочки: `Boolean(favorites.indexOf(id))` врал для первого избранного — у него индекс `0`, а `Boolean(0)` это `false`, звезда казалась выключенной. Плюс `toggle` менял тот же массив через `push`/`splice` и передавал его в `setFavorites` — React думал, что ничего не изменилось, и экран обновлялся как попало. Исправил на `includes` и создание нового массива.

2. «Обновлено N сек назад»: таймер брал старое значение `seconds` из замыкания (эффект с `[]`), поэтому счётчик застывал. Проп `since` вообще не читался — после «Обновить» время не сбрасывалось. Пересчитал секунды от `since`, повесил эффект на момент времени и добавил `clearInterval`.

## Как я использовал ИИ

Cursor (агент в чате): по README разобрали репозиторий, написали экран, починили чужой код, добавили поиск.

Проверка с моей стороны: читал диффы и сами баги в `useFavorites` / `UpdatedAgo` до правки — чтобы понимать «почему», а не только «что поменяли»; прогнал `npx tsc --noEmit`. Имеет смысл руками в браузере: фильтры, поиск («Зенит», пустой запрос), ошибка сети, звёзды по одной, «Обновить» и сброс таймера.

На что смотреть у ИИ: URL в `config` с `OWNER/REPO` сам по себе не заработает — без подстановки своего raw URL экран всегда в ошибке; это легко пропустить, если не открыть приложение.

## Что улучшил бы, будь ещё 10 минут

Сохранение избранного между запусками (`AsyncStorage`): после перезагрузки звёзды сейчас сбрасываются. Ещё — простой тест на `filterMatches` / `searchMatches`, чтобы логика фильтра не разъехалась при правках.
